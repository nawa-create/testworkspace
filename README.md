# FAX受信データ検証システム

運送業者から受信したFAXデータ（OCR処理済み）を人間が確認・検証するためのGoogle Apps Script（GAS）ベースのWebアプリケーションです。

## 機能

- ✅ スプレッドシートからデータを自動取得
- ✅ 3カラムレイアウト（一覧/詳細/画像プレビュー）
- ✅ Google Drive画像のプレビュー表示
- ✅ ステータス管理（対象外/未チェック/チェック済み）
- ✅ 受信日時の降順で自動ソート
- ✅ チェック済みデータは非表示（パフォーマンス最適化）

## システム要件

- Googleアカウント
- スプレッドシートへのアクセス権限
- Google Apps Scriptの実行権限

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「FAX受信データ検証システム」に変更

### 2. ファイルのアップロード

#### Code.gsの作成
1. デフォルトの`Code.gs`ファイルが開いている状態で、本リポジトリの`Code.gs`の内容をコピー
2. 全て貼り付けて保存（Ctrl+S または Cmd+S）

#### Index.htmlの作成
1. 左サイドバーの「+」ボタン → 「HTML」を選択
2. ファイル名を「Index」と入力（拡張子は自動的に.htmlになります）
3. 本リポジトリの`Index.html`の内容をコピー
4. 全て貼り付けて保存

### 3. スプレッドシートIDの設定

`Code.gs`の2行目のスプレッドシートIDが正しいか確認してください：

```javascript
const SPREADSHEET_ID = '1sT_UQFSmWBuUza4H1Xp1nmgWYqS0WbvcuhjhSjtNvE8';
```

### 4. デプロイ

1. 右上の「デプロイ」ボタン → 「新しいデプロイ」をクリック
2. 「種類の選択」（歯車アイコン）→ 「ウェブアプリ」を選択
3. 以下の設定を行う：
   - **説明**: 任意（例：「初回デプロイ」）
   - **次のユーザーとして実行**: 自分（あなたのGoogleアカウント）
   - **アクセスできるユーザー**: 全員
4. 「デプロイ」をクリック
5. 権限の承認画面が表示される場合：
   - 「アクセスを承認」をクリック
   - Googleアカウントを選択
   - 「詳細」→ 「（プロジェクト名）に移動」をクリック
   - 「許可」をクリック
6. デプロイ完了後、**ウェブアプリのURL**をコピー

### 5. アクセス

コピーしたURLをブラウザで開くと、FAX受信データ検証システムが起動します。

## 使い方

### 基本操作

1. **データの確認**
   - 左側の一覧から確認したいデータをクリック
   - 中央に詳細情報が表示されます
   - 右側にFAX画像のプレビューが表示されます

2. **ステータスの変更**
   - データを選択後、下部のボタンをクリック
   - **対象外**: このデータは確認対象外
   - **未チェック**: 未確認状態に戻す
   - **チェック済み**: 確認完了（一覧から削除されます）

3. **データの並び順**
   - 受信日時が新しいものから順に表示されます

### 注意事項

- ステータスを「チェック済み」にすると、そのデータは一覧に表示されなくなります
- スプレッドシート上では全てのデータが保持されています
- ページをリロードすると最新のデータが読み込まれます

## スプレッドシート構成

| 列 | 項目名 | 説明 |
|---|---|---|
| A | 受信日時 | FAXを受信した日時 |
| B | 得意先名 | 得意先の名称 |
| C | 納入先名 | 納入先の名称 |
| D | 依頼主名 | 依頼主の名称 |
| E | 納期 | 納品期日 |
| F | 商品名 | 商品の名称 |
| G | 荷姿 | 荷物の形態 |
| H | 数量 | 数量 |
| I | 備考 | 備考・メモ |
| J | 画像URL | Google DriveのURL |
| K | ステータス | 対象外/未チェック/チェック済み |

## 更新方法

コードを修正した後：

1. 保存（Ctrl+S または Cmd+S）
2. 「デプロイ」→ 「デプロイを管理」
3. 既存のデプロイの「鉛筆アイコン」（編集）をクリック
4. 「バージョン」を「新バージョン」に変更
5. 「デプロイ」をクリック

URLは変更されません。

## トラブルシューティング

### ⚠️ 「データを読み込んでいます」が表示され続ける

これは最も一般的な問題で、**デプロイ設定が正しくない**ことが原因です。

#### 原因1: テストボタンで開いている

❌ **間違い**: GASエディタの「テスト」ボタンで開いている
✅ **正しい**: 「デプロイ」から発行された**ウェブアプリのURL**で開く

**解決方法:**
1. GASエディタで「デプロイ」→「デプロイを管理」を開く
2. 「ウェブアプリ」のURLをコピー（例: `https://script.google.com/macros/s/XXXXX/exec`）
3. **新しいタブ**でそのURLを開く

#### 原因2: デプロイが古い

コードを更新した後、デプロイを更新していない可能性があります。

**解決方法:**
1. 「デプロイ」→「デプロイを管理」
2. 既存のデプロイの鉛筆アイコン（編集）をクリック
3. 「バージョン」を「新バージョン」に変更
4. 「デプロイ」をクリック
5. ブラウザでページを**強制リロード**（Ctrl+F5 または Cmd+Shift+R）

#### 原因3: アクセス権限の設定ミス

**解決方法:**
1. 「デプロイ」設定を確認
2. 「次のユーザーとして実行」→ **自分（あなたのGoogleアカウント）**
3. 「アクセスできるユーザー」→ **全員**
4. 再度デプロイ

#### デバッグ方法

画面に表示される「接続テスト」ボタンをクリック:
- ✅ **接続成功**: スプレッドシートやデータの問題
- ❌ **エラー**: デプロイ設定の問題

**ブラウザのコンソール（F12キー）を確認:**
```
[LOAD] google.script.run: 利用可能  ← これが表示されればOK
[LOAD] google.script.run: 利用不可  ← デプロイURLで開いていない
```

### データが表示されない（接続は成功している場合）

- スプレッドシートIDが正しいか確認
- シート名「FAX受信データ」が存在するか確認
- スプレッドシートへのアクセス権限があるか確認
- GASエディタの「実行ログ」を確認

### 画像が表示されない

- Google DriveのURLが正しいか確認
- 画像ファイルへのアクセス権限があるか確認（リンクを知っている全員が閲覧可能にする）
- URLの形式：`https://drive.google.com/file/d/FILE_ID/view`

### ステータスが更新されない

- スプレッドシートの編集権限があるか確認
- ブラウザのコンソールでエラーを確認
- GASエディタの「実行ログ」でエラーを確認
